# Photos

The course currently uses **ink-wash gradient heroes** so there are no broken images. To use real photography:

1. Drop files here in `photos/`.
2. In `assets/css/main.css`, find the commented `url("photos/…")` line in `.title` (and add similar lines to `.page-hero` per lesson if desired) and uncomment it.

## Wanted (to be confirmed with the school / museum)

| File (suggested) | Use | Notes |
|---|---|---|
| `hero-southern-branch.jpg` | Course Home hero | The museum exterior / lake bridge / art hill. Building, not people. ≥ 1920×1080, landscape. |
| `gallery-*.jpg` | Per-lesson heroes | One ambience shot per gallery, if licensed. |
| `students-on-site.jpg` | "Young docents" in action | Requires student image-rights consent before publishing. |

## Important — rights

- **Museum images are copyrighted.** Do not scrape from the NPM site or social media. Confirm licensing with the National Palace Museum · Southern Branch, or keep the gradient/text treatment.
- **Student portraits** need image-rights consent from the school before going public.
- Use the **building / campus / landscape** for banners, never volatile numbers or unconsented faces.
